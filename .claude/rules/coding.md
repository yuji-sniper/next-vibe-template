# 実装時・プラン時ののルール

## 基本原則

共通:
- フロントエンドの実装・プランの依頼された場合は、frontend-codingのskillsを使用してください。
- バックエンドの実装・プランの依頼された場合は、backend-codingのskillsを使用してください。
- 必要があればcontext7のMCPを使ってドキュメントを調べてください。

ユーザーから実装を依頼された場合:
- パッケージ管理はpnpmを使用してください。
- コンポーネントのテスト実装を依頼された際は、component-testingのskillsを使用してください。
- 必要があればcontext7のMCPを使ってドキュメントを調べてください。
- 実装後は、実装サマリーを.docs/summaries/配下にファイル出力してください。
